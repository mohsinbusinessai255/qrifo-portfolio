# Qrifo – QR & Barcode Generator Platform

🌐 **Live Website:** https://qrifo.com

Qrifo is a web-based platform that provides free QR code generation, barcode generation, and scanning tools, with AI-powered explanations to help users understand scanned results.

## 🚀 Key Features

- QR Code Generator
- Barcode Generator
- QR Code Scanner
- Barcode Scanner
- AI-powered QR & Barcode Explanation
- Multiple QR code use cases
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Gemini API
- Vercel

## 🎯 Project Objective

The goal of Qrifo is to make QR code and barcode tools accessible through one simple, user-friendly web platform.
